# Current-site parity rebuild

This branch rebuilds the public Larasser MyWebsite presentation as a static, maintainable site while keeping the existing public content and URL structure as the reference.

Principles:
- preserve public information and project breadth
- keep current public URL paths where practical
- use local source images already captured from the public site
- retain the Larasser visual identity and supplied company mark
- stay recognisably close to the current public site without forcing a pixel-for-pixel copy
- keep the approved clear reference-category selection as a navigation pattern
- add a new `Sonderanfertigungen` grouping only as a curated navigation layer over already source-backed Larasser projects; do not invent new projects or claims
- add a structured `Bauteilanfrage` for Lohnbiegen/Lohnschneiden, inspired by a product configurator pattern but without invented prices, cart/checkout, service limits or unsupported manufacturing promises
- improve responsive behavior, accessibility, performance and technical SEO without changing the company's public claims on our own
- keep the GitHub Pages demo noindex/nofollow until production approval
- do not change production DNS, IONOS, email, hosting or form processing

Known source contradictions remain flagged in SOURCE_AUDIT.md and are not silently resolved. The homepage therefore uses the safer verified facts `gegründet 1996`, `2 Meister` and `EN 1090-2 EXC2` instead of disputed experience/employee counters.
